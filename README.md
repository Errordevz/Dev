# Dev
Demo's decision making model , part of the DEMO lineup (DEMO mcp , DEMO ai) will be merged into the demo mcp and the individual dev will be open source :) 


## Hosted service

The reference Render service is `https://dev-htce.onrender.com`. Public web chat requires no account and the browser never receives the model provider credential. The optional `DEV_API_KEY` is generated by `POST /api/key`, encrypted with AES-256-GCM, encoded as base64url, and shown only in that issuance response.
